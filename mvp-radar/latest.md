# PlugNX MVP Radar — 2026-08-09

1. **결론**: 첫 별도 MVP는 다국어 교육 이수와 위험작업 배치 로그를 묶는 SafetyPass가 적합하다.
2. **So what**: 2주 동안 제조기업 안전·인사 담당자의 증빙 업무와 지불의사를 먼저 검증하고, 코드 범위는 확인 링크·타임스탬프·CSV 내보내기로 제한한다.
3. **확신도**: 중간 — 반복 사고와 기록 공백은 확인됐지만 별도 예산과 구매 주체는 고객 인터뷰 전이다.

## 지금 검증할 MVP

### SafetyPass — **추천**

다국어 안전교육 이수와 위험작업 배치 확인을 타임스탬프로 남기는 외국인 근로자 증빙 원장

- 고객 / 지불 주체: 외국인 근로자를 고용한 제조·농축산 기업 / 기업 안전·인사 담당 부서
- 반복 문제 / 대체재: 자료는 여러 언어로 배포되지만 개인별 이해 확인, 이수, 실제 작업 배치 증빙이 종이와 엑셀에 흩어진다. / 종이 서명부, 메신저 사진, 엑셀 명단
- 제품 / 수익모델: 모바일 확인 링크와 기업용 교육·배치 로그 대시보드 / 사업장 월 구독 또는 안전교육 사업자 화이트라벨 [목표·가정]
- 해자: 데이터, 채널, 전환비용
- 점수: 시장 4 · 페인 5 · WTP 4 · RTW 4 · 정책 4 · 구현 5 · 시너지 5 = **31/35**
- 판정 / 규제 리스크: Now / 중간
- 왜 지금: 사고와 긴급 점검이 반복되는 동안 배포 자료는 늘었지만 기업의 개인별 증빙 공백은 남아 있다.
- 이게 안 되는 이유: 기존 안전교육 사업자가 같은 로그 기능을 빠르게 붙이거나 기업이 현재 서명부로 충분하다고 판단할 수 있다.
- 첫 검증 질문: 기업은 교육 콘텐츠가 아니라 감사 가능한 개인별 교육·작업배치 로그에 별도 예산을 쓰는가?
- 2주 MVP: 다국어 교육 확인 링크, 근로자 본인 확인, 교육·배치 타임스탬프, 기업 CSV 내보내기
- 성공 기준: 기업 인터뷰 5곳 중 3곳이 실제 명단으로 파일럿을 진행하겠다고 답한다 [목표·가정]
- 중단 기준: 별도 예산 주체가 없거나 개인별 로그가 감사·보험·원청 대응에 쓰이지 않으면 독립 제품을 중단한다 [목표·가정]

### WorkCredential

고용주가 확인한 직무·근속·급여·교육 이력을 근로자 동의로 재사용하는 제출용 고용이력 패스포트

- 고객 / 지불 주체: 외국인 고용기업과 외국인 금융상품을 설계하는 금융사 / 금융사 상품·리스크 부서 또는 대형 고용기업
- 반복 문제 / 대체재: 외국인은 이직·금융·주거 과정마다 재직과 소득 서류를 반복 제출하고 기관은 진위와 최신성을 다시 확인한다. / 재직증명서, 급여명세서 PDF, 전화 확인
- 제품 / 수익모델: 동의 기반 고용이력 지갑과 기관용 조회 리포트 / 기관용 조회·검증 워크플로 구독 [목표·가정]
- 해자: 데이터, 채널, 전환비용
- 점수: 시장 4 · 페인 4 · WTP 4 · RTW 5 · 정책 4 · 구현 4 · 시너지 5 = **30/35**
- 판정 / 규제 리스크: Now / 중간
- 왜 지금: 금융 성장과 부실 신호가 동시에 커져 행동 데이터와 다른 고용주 확인 데이터의 가치가 드러났다.
- 이게 안 되는 이유: 금융사는 자체 서류 확인으로 충분하다고 보거나 개인정보·신용정보 검토 때문에 조달 주기가 길어질 수 있다.
- 첫 검증 질문: 금융사가 실제 의사결정 보조에 쓰려는 고용 필드와 허용 가능한 동의·보관 구조는 무엇인가?
- 2주 MVP: 더미 고용이력 업로드, 근로자 동의 화면, 제출용 고용이력 리포트, 조회 로그
- 성공 기준: 금융·렌탈 파트너 인터뷰 3곳 중 1곳이 샘플 데이터 계약과 PoC 필드 협의를 요청한다 [목표·가정]
- 중단 기준: 고용주 확인 데이터가 기존 재직증명서 대비 의사결정 가치가 없으면 금융용 제품화를 중단한다 [목표·가정]

### HousingReady

외국인이 정책주거 상담 전에 체류·거주·소득 준비 항목을 확인하고 기관이 동일한 스키마로 받는 체크리스트

- 고객 / 지불 주체: 외국인 주민과 지자체·주거지원기관 / 지자체 또는 주거지원기관
- 반복 문제 / 대체재: 지원 가능 여부와 필요한 서류가 기관마다 흩어져 외국인은 반복 방문하고 담당자는 같은 항목을 다시 확인한다. / 전화 문의, 번역 안내문, 대면 상담
- 제품 / 수익모델: 사실 대조형 준비 체크리스트와 기관용 접수 스키마 / 기관 연간 사용료 또는 시범사업 용역 [목표·가정]
- 해자: 정책, 데이터, 전환비용
- 점수: 시장 3 · 페인 5 · WTP 3 · RTW 4 · 정책 3 · 구현 4 · 시너지 4 = **26/35**
- 판정 / 규제 리스크: Next / 중간
- 왜 지금: 정책 배제 문제가 공론화돼 제도 개정 전에 외국인 적격 확인 절차와 데이터 항목을 제안할 창이 열렸다.
- 이게 안 되는 이유: 법 개정 건의가 실제 시행으로 이어지지 않을 수 있고 공공 영업주기가 2주 MVP보다 길다.
- 첫 검증 질문: 지자체 상담 담당자는 어떤 반복 확인 업무를 줄이기 위해 표준 접수 스키마를 도입할 것인가?
- 2주 MVP: 지원제도 준비 항목 화면, 기관별 서류 체크리스트, 상담용 요약 리포트
- 성공 기준: 지자체·지원기관 3곳이 공통 접수 항목 5개 이상에 합의한다 [목표·가정]
- 중단 기준: 기관별 규칙 차이로 공통 스키마가 성립하지 않거나 공식 제도 근거가 확보되지 않으면 Monitor로 되돌린다 [목표·가정]

## 참고

비자·노무·세무·금융 관련 내용은 법적 효력이 없는 참고 정보이며, 제품화 전에 전문가와 최신 1차 출처 확인이 필요합니다. 기사 기반 정책 신호는 발표·건의와 시행을 구분해야 합니다.
