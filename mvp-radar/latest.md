## 지금 검증할 MVP

### PreKYC Fit — **추천**

체류·재직·소득 필드를 미리 정리해 어느 상품이 개설 가능한지 사전 판정하는 온보딩 도구

- 고객 / 지불 주체: 계좌·카드 개설을 시도하는 국내 거주 외국인 / 개설 반려율을 낮추려는 은행·인터넷은행 온보딩 조직
- 반복 문제 / 대체재: 서류가 무엇이 부족한지 모른 채 창구를 왕복하고, 반려 사유가 데이터로 남지 않아 개선되지 않는다. / 창구 방문 후 반려, 커뮤니티 경험담, 지자체 협약 개별 처리
- 제품 / 수익모델: 사전 진단 웹 + 보완 서류 체크리스트 + 은행용 반려 사유 집계 / 은행 건당 과금(개설 승인율 개선분 기준) [목표·가정]
- 해자: 데이터, 채널, 전환비용
- 점수: 시장 5 · 페인 5 · WTP 4 · RTW 5 · 정책 4 · 구현 4 · 시너지 5 = **32/35**
- 판정 / 규제 리스크: Now / 중간
- 왜 지금: 2026-11-19 신호 '업계는 계좌를 열어 주지 않고 비켜 갔다 — 쿠콘 '비플월렛', 여권 기반 본인확인만으로 국내'(56만)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 4건 · 키워드 적중 16회).
- 이게 안 되는 이유: 반려 사유가 데이터 부족이 아니라 AML·규제 회피 판단이면 데이터를 줘도 문이 열리지 않는다.
- 첫 검증 질문: 은행은 외국인 건의 반려율과 반려 사유를 지표로 관리하는가?
- 2주 MVP: 체류·재직·소득 문답 수집, 상품별 요건 매핑, 보완 서류 체크리스트, 반려 사유 코드 집계
- 성공 기준: 은행 2곳이 반려 사유 필드 정의에 구체적 수정 요구를 낸다 [목표·가정]
- 중단 기준: 2곳 이상이 '내부 데이터로 자체 확보 예정'이라고 답하면 중단한다 [목표·가정]

### Field Schema

회사마다 다른 급여 원장을 재직·근속·급여지속성·실효체류 4필드로 정규화해 점수 없이 신호만 넘기는 규격

- 고객 / 지불 주체: 외국인 여신·카드 심사를 늘려야 하는 금융기관 / 금융기관 심사·리스크 조직
- 반복 문제 / 대체재: 외국인 심사의 판별 변수가 체류기간 하나뿐이고, 재직증명서 사본은 계약임금만 보여준다. / 체류기간 단일 변수 + 서류 사본 수취
- 제품 / 수익모델: 표준 스키마 문서 + 익명 샘플 검증 리포트 + 조회 API 규격 / 조회 건당 과금 [목표·가정]
- 해자: 데이터, 채널
- 점수: 시장 5 · 페인 5 · WTP 4 · RTW 5 · 정책 4 · 구현 3 · 시너지 5 = **31/35**
- 판정 / 규제 리스크: Next / 중간
- 왜 지금: 2026-11-19 신호 ''국내 현재 상태'에 첫 경쟁자가 붙었다 — 헥토, 출입국 기록 확인을 KYC API 한 줄로'(2건)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 4건 · 키워드 적중 9회).
- 이게 안 되는 이유: 고용기업 원장 연동 동의를 얻는 것이 프로덕트가 아니라 영업의 문제이고, 대형 CB가 원천을 확보하면 정규화 계층이 사라진다.
- 첫 검증 질문: 금융기관은 체류기간 외 변수에 조회료를 지불할 의사가 있는가?
- 2주 MVP: 4필드 표준 스키마 v0.1, 익명 샘플 리포트 3종, 실효 잔여기간 산정 근거 문서, 감사 로그 설계
- 성공 기준: 금융·카드사 2곳이 필드 정의에 수정 요구를 낸다 [목표·가정]
- 중단 기준: 3곳 모두 '체류기간만으로 충분하다'고 답하면 고용주 과금으로 설계를 되돌린다 [목표·가정]

### Rule Sentinel

제도 개정문을 매일 읽고 우리 회사 근로자 중 오늘 새로 예외가 된 사람만 골라 주는 기한 파수꾼

- 고객 / 지불 주체: 외국인을 여러 사업장에 두고 노무 담당이 1~2명인 기업 / 고용주(시공사·제조사)
- 반복 문제 / 대체재: 제도가 자주 바뀌는데 사내 원장과 대조할 방법이 없어 개정 때마다 사람이 표를 다시 짠다. / 엑셀 만기표 + 행정사 전화 확인 + 고시 눈으로 훑기
- 제품 / 수익모델: 사내 원장 업로드 + 개정 대조 + 예외 목록 일일 메일 / 사업장 월 구독 [목표·가정]
- 해자: 데이터, 정책, 전환비용
- 점수: 시장 4 · 페인 5 · WTP 4 · RTW 4 · 정책 5 · 구현 4 · 시너지 4 = **30/35**
- 판정 / 규제 리스크: Now / 중간
- 왜 지금: 2026-11-19 신호 '업계는 계좌를 열어 주지 않고 비켜 갔다 — 쿠콘 '비플월렛', 여권 기반 본인확인만으로 국내'(56만)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 4건 · 키워드 적중 9회).
- 이게 안 되는 이유: 대형 노무법인이 자문 상품으로 흡수하기 쉽고, 개정이 잦아드는 국면에는 긴급성이 떨어진다.
- 첫 검증 질문: 담당자는 개정 때문에 놓친 건을 실제로 경험했는가?
- 2주 MVP: 엑셀 원장 수신, 개정 조항 추출, 예외 근로자 판정, 일일 메일 발송
- 성공 기준: 시공사 5곳 중 3곳이 '이 목록이 없었으면 놓쳤을 건'을 구체적으로 지목한다 [목표·가정]
- 중단 기준: 2주간 새로 발생한 예외가 0건이면 중단한다 [목표·가정]

## 참고

이 리포트는 누적 브리핑 신호와 검증된 MVP 패턴을 대조한 참고 정보이며 법적·재무적 효력이 없다. 점수와 수익 가정은 미검증값이고, 정책·비자·금융 판단은 반드시 전문가와 최신 1차 출처(하이코리아·법제처·고용노동부·금융위)로 확인해야 한다.
