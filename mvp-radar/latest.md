## 지금 검증할 MVP

오늘은 빌드 게이트를 통과한 후보가 없습니다. 신호를 누적하고 검증을 계속합니다.
### Field Schema

회사마다 다른 급여 원장을 재직·근속·급여지속성·실효체류 4필드로 정규화해 점수 없이 신호만 넘기는 규격

- 고객 / 지불 주체: 외국인 여신·카드 심사를 늘려야 하는 금융기관 / 금융기관 심사·리스크 조직
- 반복 문제 / 대체재: 외국인 심사의 판별 변수가 체류기간 하나뿐이고, 재직증명서 사본은 계약임금만 보여준다. / 체류기간 단일 변수 + 서류 사본 수취
- 제품 / 수익모델: 표준 스키마 문서 + 익명 샘플 검증 리포트 + 조회 API 규격 / 조회 건당 과금 [목표·가정]
- 해자: 데이터, 채널
- 점수: 시장 5 · 페인 5 · WTP 4 · RTW 5 · 정책 4 · 구현 3 · 시너지 5 = **31/35**
- 판정 / 규제 리스크: Next / 중간
- 왜 지금: 2026-10-15 신호 '한패스가 '외국인 필수 슈퍼앱'을 선언했다 — 송금 사업자가 생활 레이어 전체를 접수하러 왔다'(3명)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 4건 · 키워드 적중 13회).
- 이게 안 되는 이유: 고용기업 원장 연동 동의를 얻는 것이 프로덕트가 아니라 영업의 문제이고, 대형 CB가 원천을 확보하면 정규화 계층이 사라진다.
- 첫 검증 질문: 금융기관은 체류기간 외 변수에 조회료를 지불할 의사가 있는가?
- 2주 MVP: 4필드 표준 스키마 v0.1, 익명 샘플 리포트 3종, 실효 잔여기간 산정 근거 문서, 감사 로그 설계
- 성공 기준: 금융·카드사 2곳이 필드 정의에 수정 요구를 낸다 [목표·가정]
- 중단 기준: 3곳 모두 '체류기간만으로 충분하다'고 답하면 고용주 과금으로 설계를 되돌린다 [목표·가정]

### Stay Info API

체류자격·잔여기간·근로가능 여부를 동의 기반으로 즉시 확인해 주는 조회 API와 다국어 안내 생성

- 고객 / 지불 주체: 외국인 응대에 전담 인력을 쓰는 지방은행·통신사 창구 / 지방은행(창구 인건비 대체)
- 반복 문제 / 대체재: 설명과 확인이 필요한 업무라 대면 창구에 사람이 붙어 있고, 그 비용이 계속 늘어난다. / 전담 창구 직원, 통역 인력, 서류 육안 확인
- 제품 / 수익모델: 조회 API + 다국어 안내문 자동 생성 / 조회 건당 과금(상한은 창구 인건비) [목표·가정]
- 해자: 데이터, 채널, 전환비용
- 점수: 시장 4 · 페인 4 · WTP 4 · RTW 4 · 정책 4 · 구현 3 · 시너지 5 = **28/35**
- 판정 / 규제 리스크: Next / 중간
- 왜 지금: 2026-10-15 신호 '한패스가 '외국인 필수 슈퍼앱'을 선언했다 — 송금 사업자가 생활 레이어 전체를 접수하러 왔다'(3명)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 6건 · 키워드 적중 10회).
- 이게 안 되는 이유: 공적 확인 채널과 경합하고, 동의 취득 흐름이 창구 프로세스에 얹히지 않으면 쓰이지 않는다.
- 첫 검증 질문: 지방은행은 창구 처리 건수를 비용으로 계량하고 있는가?
- 2주 MVP: 동의 취득 흐름, 체류 항목 조회 규격, 다국어 안내문 생성, 감사 로그
- 성공 기준: 지방은행 1곳이 창구 건당 처리시간을 데이터로 제시한다 [목표·가정]
- 중단 기준: 창구 비용을 계량하지 않는다는 답이 2곳 이상이면 중단한다 [목표·가정]

### Settle Guide

입국 30일 안에 처리해야 할 행정·생활 절차를 지자체별로 안내하는 다국어 온보딩 가이드

- 고객 / 지불 주체: 입국 초기 외국인 주민과 정주 지원 지자체 / 지자체 외국인·인구정책 부서
- 반복 문제 / 대체재: 계좌·통신·등록·의료 절차가 지자체마다 다르고 안내는 담당자 개인 역량에 의존한다. / 지자체 출장 서비스, 기관 개별 협약, 커뮤니티 구전
- 제품 / 수익모델: 지자체별 절차 데이터 + 다국어 체크리스트 / 지자체 구독 [목표·가정]
- 해자: 정책, 채널
- 점수: 시장 4 · 페인 4 · WTP 3 · RTW 3 · 정책 5 · 구현 4 · 시너지 3 = **26/35**
- 판정 / 규제 리스크: Later / 낮음
- 왜 지금: 2026-10-15 신호 '한패스가 '외국인 필수 슈퍼앱'을 선언했다 — 송금 사업자가 생활 레이어 전체를 접수하러 왔다'(3명)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 4건 · 키워드 적중 9회).
- 이게 안 되는 이유: 지자체가 이미 자체 안내물을 만들고 있고 예산이 인쇄물에 묶여 있을 수 있다.
- 첫 검증 질문: 지자체는 안내 절차를 데이터로 관리하려 하는가, 인쇄물로 충분하다고 보는가?
- 2주 MVP: 지자체 3곳 절차 수집, 다국어 체크리스트, 진행 상태 저장
- 성공 기준: 지자체 1곳이 자체 안내물 대체를 검토한다 [목표·가정]
- 중단 기준: 3곳 모두 인쇄물로 충분하다고 답하면 후보에서 내린다 [목표·가정]
