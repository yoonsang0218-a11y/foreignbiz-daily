## 지금 검증할 MVP

### Rule Sentinel — **추천**

제도 개정문을 매일 읽고 우리 회사 근로자 중 오늘 새로 예외가 된 사람만 골라 주는 기한 파수꾼

- 고객 / 지불 주체: 외국인을 여러 사업장에 두고 노무 담당이 1~2명인 기업 / 고용주(시공사·제조사)
- 반복 문제 / 대체재: 제도가 자주 바뀌는데 사내 원장과 대조할 방법이 없어 개정 때마다 사람이 표를 다시 짠다. / 엑셀 만기표 + 행정사 전화 확인 + 고시 눈으로 훑기
- 제품 / 수익모델: 사내 원장 업로드 + 개정 대조 + 예외 목록 일일 메일 / 사업장 월 구독 [목표·가정]
- 해자: 데이터, 정책, 전환비용
- 점수: 시장 4 · 페인 5 · WTP 4 · RTW 4 · 정책 5 · 구현 4 · 시너지 4 = **30/35**
- 판정 / 규제 리스크: Now / 중간
- 왜 지금: 2026-11-12 신호 'LH, 건설현장 2곳서 임금 50~70% 선지급 시범 — 생체인식 출역기록에 핀테크를 붙였고,'(2곳)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 3건 · 키워드 적중 8회).
- 이게 안 되는 이유: 대형 노무법인이 자문 상품으로 흡수하기 쉽고, 개정이 잦아드는 국면에는 긴급성이 떨어진다.
- 첫 검증 질문: 담당자는 개정 때문에 놓친 건을 실제로 경험했는가?
- 2주 MVP: 엑셀 원장 수신, 개정 조항 추출, 예외 근로자 판정, 일일 메일 발송
- 성공 기준: 시공사 5곳 중 3곳이 '이 목록이 없었으면 놓쳤을 건'을 구체적으로 지목한다 [목표·가정]
- 중단 기준: 2주간 새로 발생한 예외가 0건이면 중단한다 [목표·가정]

### PreKYC Fit

체류·재직·소득 필드를 미리 정리해 어느 상품이 개설 가능한지 사전 판정하는 온보딩 도구

- 고객 / 지불 주체: 계좌·카드 개설을 시도하는 국내 거주 외국인 / 개설 반려율을 낮추려는 은행·인터넷은행 온보딩 조직
- 반복 문제 / 대체재: 서류가 무엇이 부족한지 모른 채 창구를 왕복하고, 반려 사유가 데이터로 남지 않아 개선되지 않는다. / 창구 방문 후 반려, 커뮤니티 경험담, 지자체 협약 개별 처리
- 제품 / 수익모델: 사전 진단 웹 + 보완 서류 체크리스트 + 은행용 반려 사유 집계 / 은행 건당 과금(개설 승인율 개선분 기준) [목표·가정]
- 해자: 데이터, 채널, 전환비용
- 점수: 시장 5 · 페인 5 · WTP 4 · RTW 5 · 정책 4 · 구현 4 · 시너지 5 = **32/35**
- 판정 / 규제 리스크: Now / 중간
- 왜 지금: 2026-11-12 신호 '카카오뱅크 '외국인통장' 출시 한 달 만에 2만좌 — 전용 앱을 만들지 않은 쪽이 먼저 숫자를'(2만)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 3건 · 키워드 적중 7회).
- 이게 안 되는 이유: 반려 사유가 데이터 부족이 아니라 AML·규제 회피 판단이면 데이터를 줘도 문이 열리지 않는다.
- 첫 검증 질문: 은행은 외국인 건의 반려율과 반려 사유를 지표로 관리하는가?
- 2주 MVP: 체류·재직·소득 문답 수집, 상품별 요건 매핑, 보완 서류 체크리스트, 반려 사유 코드 집계
- 성공 기준: 은행 2곳이 반려 사유 필드 정의에 구체적 수정 요구를 낸다 [목표·가정]
- 중단 기준: 2곳 이상이 '내부 데이터로 자체 확보 예정'이라고 답하면 중단한다 [목표·가정]

### Stay Info API

체류자격·잔여기간·근로가능 여부를 동의 기반으로 즉시 확인해 주는 조회 API와 다국어 안내 생성

- 고객 / 지불 주체: 외국인 응대에 전담 인력을 쓰는 지방은행·통신사 창구 / 지방은행(창구 인건비 대체)
- 반복 문제 / 대체재: 설명과 확인이 필요한 업무라 대면 창구에 사람이 붙어 있고, 그 비용이 계속 늘어난다. / 전담 창구 직원, 통역 인력, 서류 육안 확인
- 제품 / 수익모델: 조회 API + 다국어 안내문 자동 생성 / 조회 건당 과금(상한은 창구 인건비) [목표·가정]
- 해자: 데이터, 채널, 전환비용
- 점수: 시장 4 · 페인 4 · WTP 4 · RTW 4 · 정책 4 · 구현 3 · 시너지 5 = **28/35**
- 판정 / 규제 리스크: Next / 중간
- 왜 지금: 2026-11-12 신호 '카카오뱅크 '외국인통장' 출시 한 달 만에 2만좌 — 전용 앱을 만들지 않은 쪽이 먼저 숫자를'(2만)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 4건 · 키워드 적중 7회).
- 이게 안 되는 이유: 공적 확인 채널과 경합하고, 동의 취득 흐름이 창구 프로세스에 얹히지 않으면 쓰이지 않는다.
- 첫 검증 질문: 지방은행은 창구 처리 건수를 비용으로 계량하고 있는가?
- 2주 MVP: 동의 취득 흐름, 체류 항목 조회 규격, 다국어 안내문 생성, 감사 로그
- 성공 기준: 지방은행 1곳이 창구 건당 처리시간을 데이터로 제시한다 [목표·가정]
- 중단 기준: 창구 비용을 계량하지 않는다는 답이 2곳 이상이면 중단한다 [목표·가정]
