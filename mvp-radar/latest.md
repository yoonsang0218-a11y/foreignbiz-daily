- 왜 지금: 2026-09-08 신호 '법무부가 유학생 53만명의 입학–졸업–취업–정주를 처음으로 끝까지 추적했다'(53만명)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 6건 · 키워드 적중 15회).

### Visa FitCheck — **추천**

학력·재직·소득·체류이력을 넣으면 갈 수 있는 체류 경로를 순위로 보여주는 사전 진단

- 고객 / 지불 주체: 졸업을 앞둔 유학생과 숙련전환을 노리는 E-9 근로자 / 대학 국제교류센터·지자체 정착 담당(기관 예산)
- 반복 문제 / 대체재: 비자 코드가 39개로 흩어져 있고 기준이 계속 바뀌어 당사자도 대학 직원도 갈 수 있는 경로를 모른다. / 대학 직원 수작업 상담, 행정사 유료 상담, 커뮤니티 경험담
- 제품 / 수익모델: 대화형 진단 웹 + 경로 순위 카드 + 부족 요건 역산 / 당사자 무료, 대학·지자체 연간 구독 [목표·가정]
- 해자: 데이터, 정책, 채널
- 점수: 시장 5 · 페인 5 · WTP 3 · RTW 4 · 정책 5 · 구현 4 · 시너지 4 = **30/35**
- 판정 / 규제 리스크: Now / 중간
- 왜 지금: 2026-09-08 신호 '법무부가 유학생 53만명의 입학–졸업–취업–정주를 처음으로 끝까지 추적했다'(53만명)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 4건 · 키워드 적중 12회).
- 이게 안 되는 이유: 제도 개편이 진행 중이라 규칙을 지금 고정하면 재작업 비용이 크고, 법무부가 공식 도구를 무료 배포하면 대체된다.
- 첫 검증 질문: 대학은 상담 소요시간 절감에 예산을 배정하는가, 아니면 직원 업무로 흡수하는가?
- 2주 MVP: 프로필 문답 수집, 4개 코드(E-7·E-7-4·D-10·F-2-R) 규칙 테이블, 경로 순위 + 근거 조항, 부족 요건 역산
- 성공 기준: 대학 1곳 파일럿에서 상담 1건당 소요시간이 유의미하게 줄어든다 [목표·가정]
- 중단 기준: 유학생 30명 중 절반이 '학교에 물어보면 된다'고 답하면 B2C 축을 접는다 [목표·가정]

### Stay Info API

체류자격·잔여기간·근로가능 여부를 동의 기반으로 즉시 확인해 주는 조회 API와 다국어 안내 생성

- 고객 / 지불 주체: 외국인 응대에 전담 인력을 쓰는 지방은행·통신사 창구 / 지방은행(창구 인건비 대체)
- 반복 문제 / 대체재: 설명과 확인이 필요한 업무라 대면 창구에 사람이 붙어 있고, 그 비용이 계속 늘어난다. / 전담 창구 직원, 통역 인력, 서류 육안 확인
- 제품 / 수익모델: 조회 API + 다국어 안내문 자동 생성 / 조회 건당 과금(상한은 창구 인건비) [목표·가정]
- 해자: 데이터, 채널, 전환비용
- 점수: 시장 4 · 페인 4 · WTP 4 · RTW 4 · 정책 4 · 구현 3 · 시너지 5 = **28/35**
- 판정 / 규제 리스크: Next / 중간
- 왜 지금: 2026-09-08 신호 '법무부가 유학생 53만명의 입학–졸업–취업–정주를 처음으로 끝까지 추적했다'(53만명)에서 이 패턴의 문제가 다시 관측됐다(그날 카드 6건 · 키워드 적중 10회).
- 이게 안 되는 이유: 공적 확인 채널과 경합하고, 동의 취득 흐름이 창구 프로세스에 얹히지 않으면 쓰이지 않는다.
- 첫 검증 질문: 지방은행은 창구 처리 건수를 비용으로 계량하고 있는가?
- 2주 MVP: 동의 취득 흐름, 체류 항목 조회 규격, 다국어 안내문 생성, 감사 로그
- 성공 기준: 지방은행 1곳이 창구 건당 처리시간을 데이터로 제시한다 [목표·가정]
- 중단 기준: 창구 비용을 계량하지 않는다는 답이 2곳 이상이면 중단한다 [목표·가정]
